# Asset credits and provenance

This prototype uses local assets already present in the project. Their original source records were not included with the project, so their authorship and usage terms cannot be verified here.

## Character art

- `assets/characters/loki-catch.png` — horned-helmet Loki cutout used for the main character and capture/victory poses.
- `assets/characters/loki-surprise-cutout.png` — existing reaction cutout used during the alarm reaction.
- `assets/characters/loki-idle.jpg`, `assets/characters/loki-casting.jpg`, and `assets/characters/loki-surprise.png` — other pre-existing character images retained in the asset folder.

## Scene and effects

- `assets/backgrounds/vault-bg.jpg` — vault environment.
- `assets/effects/energy-barrier.jpg`, `assets/effects/particle-green.svg`, `assets/images/tesseract.jpg`, and `assets/images/mirror-tile.jpg` — local scene, effect, and puzzle art.

No external assets were downloaded for this rework. New custom multi-pose art could not be generated with the available image-generation tool, so the existing local Loki art remains in use. Treat the character and franchise art as unlicensed fan-game material unless separate rights documentation is supplied.
