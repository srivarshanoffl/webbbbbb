# Hulk: Structural Rescue

A single-screen HTML, CSS, and vanilla JavaScript 2.5D debris-pulling game.

## Run

Open `index.html` in a modern browser. If your browser restricts local asset loading, serve this folder with any static HTTP server and open the local address.

## Files

- `index.html` — game layout and screens
- `styles.css` — visual design and animations
- `game.js` — game logic and drag interaction
- `assets/` — background, obstacle art, Hulk animation frames, and sprite source archive

The Hulk sprite archive is sourced and documented in `assets/HULK-ASSET-SOURCE.txt`.
